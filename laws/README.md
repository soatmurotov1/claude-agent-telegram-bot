# laws/

Short summaries of the legislation behind the documents in `templates/investment-checklist/`.
Every `*.md` file here except this README is added to the prompt of each **document check**
(not to normal replies, to save the subscription). Keep each file short: what the document is,
who issues it, what it must contain, how long it is valid.

Each file names its lex.uz source and the date it was read. Legislation changes often: compare
with lex.uz at least once a year. `<!-- comments -->` are not sent to Claude.

Normal replies use `company.md`, which already summarises Cabinet of Ministers resolutions
No. 133, 9, 685, 169, 234 and 784.
